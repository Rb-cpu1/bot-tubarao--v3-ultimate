# Bot Tubarão V3 Ultimate

Um sistema de trading com Inteligência Artificial para análise de mercado e geração de sinais.

## Tecnologias Utilizadas

- **Frontend**: Vanilla JavaScript com HTML5/CSS3
- **IA**: TensorFlow.js para análise preditiva
- **Autenticação**: Firebase Authentication
- **Banco de Dados**: Firestore
- **Design**: Interface responsiva com animações CSS
- **Fontes**: Orbitron, Rajdhani, JetBrains Mono
- **Ícones**: Font Awesome 6.5.0

## Funcionalidades

- Sistema de login e registro com códigos de ativação
- Planos de assinatura (Básico, Pro, Elite)
- Dashboard com análise de mercado em tempo real
- Sinais de IA com confiabilidade e tempo de expiração
- Gráficos de preços atualizados
- Histórico de sinais
- Perfil do usuário
- Suporte via WhatsApp

## Como Usar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Faça login ou crie uma conta com código de ativação
4. Acesse o dashboard e comece a receber sinais de IA

## Estrutura de Arquivos

- `index.html` - Página principal da aplicação
- `style.css` - Estilos CSS da aplicação
- `manifest.json` - Configuração da PWA
- `README.md` - Documentação do projeto
